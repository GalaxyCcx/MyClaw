# 通用异常恢复（Error Recovery）

## 扩展连接异常

### 现象

- 返回“扩展未连接”或 “No tab connected”

### 处理

1. 提示用户在目标标签页点击 Browser MCP 扩展的 `Connect`
2. 用户确认后重新执行当前步骤

## 点击后新开 tab 导致连接丢失

### 现象

- 点击“详情/钻取/查看明细”后，随后工具报“扩展未连接”或 “No tab connected”
- 父页看似已点击成功，但后续 snapshot/click 均失败

### 处理

1. 立即停止重复点击，判定为“新开 tab 导致连接丢失”。
2. 提示用户切到目标新 tab 并点击 Browser MCP 扩展 `Connect`。
3. 用户确认后先 `browser_snapshot`，校验是否命中二级页锚点（标题/主表名/关键字段）。
4. 若命中，继续后续步骤；若未命中，返回父页改走“提取 URL + browser_navigate”路径。
5. 同一入口最多重试 2 次，超过后输出失败摘要并终止盲点。

## 下载页跳转后失联

### 现象

- 点击“下载/导出/明细下载”后打开新窗口
- 随后任何 Browser MCP 工具都提示未连接

### 处理

1. 终止继续点击下载入口。
2. 返回父页重新定位该入口，优先提取 URL。
3. 改用 `browser_navigate` 在当前已连接 tab 打开下载页。
4. 打开后先校验下载页锚点（标题/下载按钮）再执行下载动作。

## 下载已触发但本地未落盘

### 现象

- 任务中心显示“已成功”
- 下载按钮点击成功
- 本地下载目录未出现目标文件，或仅出现临时文件

### 处理

1. 禁止直接宣告“下载成功”，状态应为“已触发下载，待确认”。
2. 记录点击下载前时间戳 `t0`，轮询本地下载目录（建议 30~60 秒超时）。
3. 以“文件名关键字 + 修改时间 >= t0 + 大小 > 0”作为落盘判定。
4. 超时仍未命中时，输出失败摘要并建议用户检查：
   - Chrome 下载拦截/安全提示
   - 下载目录权限或路径
   - 浏览器是否弹出确认但未处理
5. 失败时补采 `browser_get_console_logs`，附上关键错误日志（如跨域、权限、下载被拦截）。

## 定位失效

### 现象

- 原 ref 失效或点击错位

### 处理

1. 立即重新 `browser_snapshot`
2. 改用“标签文本 + 就近组件”重新定位
3. 使用最新 ref 重试

## 单选项错位（点击目标项却变成其他值）

### 现象

- 日志显示点击了目标项，但字段最终显示为其他值
- 同一页面存在多个“品类组”字段，可能发生跨区块误操作

### 处理

1. 先锁定目标区块：`<目标章节标题>` + `<目标表/模块标题>`。
2. 仅在该区块内重开 `<目标字段>` 下拉。
3. 展开后立即 snapshot，使用当前 option ref 重新点击 `<目标选项>`。
4. 强校验字段展示值是否为 `<目标选项>`；不通过则禁止下一步。
5. 连续两次不通过，切换键盘选择（方向键 + Enter）或上报。

## 动态渲染导致操作丢失

### 现象

- 选项刚选中又回滚，或按钮点击无效

### 处理

1. 每个关键动作后增加短等待
2. 动作后立刻 snapshot 校验状态
3. 失败两次则切换备用策略

## 操作慢与无效重试

### 现象

- 单次点击等待时间长
- 对话中步骤很多，但有效状态变化很少

### 处理

1. 启用“单阶段最多 1 次 snapshot（失败补 1 次）”策略。
2. 成功校验后禁止重复点击同一控件。
3. 控件点击后默认短等待，查询后长等待。
4. 单步调用次数超预算立即中断并进入诊断，不继续盲点。

## 日期范围只选到单日

### 现象

- 第一次点击选了日期后弹层关闭
- 再次打开选择另一天后，前一个日期被覆盖
- 最终没有形成 `start ~ end` 区间

### 处理

1. 放弃“开两次面板”的路径，改为“一次面板完成区间”。
2. 打开面板后先点开始日，再直接点结束日，不再点击输入框。
3. 每次点日历单元格后 snapshot 校验，必要时重新取 ref。
4. 若仍失败，先重置当前日期值后再按标准流程重做。

## 结果校验失败

### 现象

- 查询后目标表不存在或数据为空

### 处理

1. 回传当前筛选条件摘要
2. 截图并说明失败发生在第几步
3. 请求用户确认业务口径或筛选条件

## 终止条件

- 同一问题连续两轮恢复仍失败时，不再盲目重试。
- 必须输出：失败步骤、已尝试策略、建议下一步。
