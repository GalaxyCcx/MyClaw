# 多选下拉组件（Multi Select）

## 适用范围

- 常见字段：大区、城市等
- 默认占位常为“无限制”
- 支持多项同时勾选

## 标准操作流程

1. 先 snapshot，定位目标字段的多选框 ref。
2. 点击组件展开下拉面板。
3. 按文本逐项点击目标选项。
4. 选择完成后点击空白处或按 `Esc` 关闭下拉。
5. 校验已选项标签或计数展示。

## 定位优先级

1. 标签文本锚定 + 就近多选框
2. 占位符文本（如“无限制”）
3. 下拉面板中的选项文本

## 备用策略

- 若下拉面板层级变化，先重新展开再 snapshot。
- 若需清空，优先点击“清空/重置/不限”类选项。

## 失败信号与恢复

- 失败信号：点选无效、选项瞬间消失、下拉自动关闭。
- 恢复步骤：
  - 重开下拉面板并重新定位
  - 一次只选择一个选项并短等待
  - 完成后统一校验已选结果
