# 表格与分页组件（Table Pagination）

## 适用范围

- 查询后出现目标表，如“[贡献拆解1]-商品分类”
- 需要采集多页数据并合并

## 标准操作流程

1. 定位目标表标题，确认命中正确数据区块。
2. 读取当前页表头和数据行。
3. 定位分页器“下一页”按钮并判断是否可用。
4. 可用则翻页并重复读取，直到末页。
5. 汇总所有页数据并执行去重。

## 定位优先级

1. 目标表标题文本
2. 表头关键列名
3. 分页器中的当前页/下一页控件

## 备用策略

- 若多个表同屏，必须先按标题锁定后再读取。
- 翻页后先等待渲染，再读取数据，避免重复抓取上一页。

## 失败信号与恢复

- 失败信号：翻页后内容不变、页码不变、数据重复。
- 恢复步骤：
  - 翻页后 snapshot 校验页码
  - 记录每页首行作为变化检查点
  - 连续两页相同则终止并上报异常

## 输出建议

- `table_name`
- `total_pages`
- `total_rows`
- `rows_by_page`
