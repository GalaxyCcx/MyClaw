# 页面元素映射（基于目标页源码）

## 页面识别锚点

- 根节点：`html#htmlRoot[lang="zh_CN"][data-theme]`
- 组件体系：Ant Design（`ant-*` 类结构）
- 任务主链：筛选区 -> 查询按钮 -> 结果表格 -> 分页/下载

> 说明：该映射固定“组件模式”，不固定单次快照 ref 和绝对 DOM 路径。

## 元素分组与定位优先级

### 1) 日期范围（当期/对比期）

- 典型特征：`ant-picker` / range 面板（或历史 `ant-calendar-range` 结构）
- 定位顺序：区块标题锚定 -> 字段标签（当期/对比期、开始/结束）-> 输入框 ref
- 执行动作：点击输入框打开面板，单次会话完成 start/end
- 后置校验：四个日期框均输出 `填前 -> 填后`，值必须命中目标

### 2) 单选下拉

- 典型特征：`ant-select`、`ant-select-selector`、`ant-select-dropdown`
- 定位顺序：区块锚定 -> 字段文本 -> 下拉 ref -> 当前展开列表 option ref
- 执行动作：展开 -> 取最新 option ref -> 点击目标项
- 后置校验：字段展示值 == 目标值

### 3) 多选下拉

- 典型特征：`ant-select` 多选模式、已选 tag 列表、占位“无限制”
- 定位顺序：字段标签 -> 多选容器 ref -> 选项 ref
- 执行动作：逐项选择，最后关闭下拉
- 后置校验：已选 tag 或计数与目标集合一致

### 4) 复选框组

- 典型特征：`ant-checkbox-group`、`ant-checkbox-wrapper`、`aria-checked`
- 定位顺序：组标题 -> 选项文本 -> 选项 ref
- 执行动作：只点“未勾选且目标需要勾选”的项
- 后置校验：勾选状态与目标集合一致

### 5) 查询按钮

- 典型特征：`ant-btn` + `ant-btn-primary` + 文本“查询”
- 定位顺序：先区块锚定 -> 区块内按钮 ref（禁止裸 `text="查询"`）
- 执行动作：单击后等待渲染
- 后置校验：至少 1 个可观测变化（加载态、更新时间、行数、指标值）
- 失败分流：若出现 `ambiguous text match`，必须回到区块锚定并重取 ref，禁止继续 text 点击重试

### 6) 表格区域

- 典型特征：`ant-table`、表头列名、行容器
- 定位顺序：表标题/模块标题 -> 表头列名 -> 行 ref
- 执行动作：读取当前页数据并结构化输出
- 后置校验：页码与行数据一致，避免重复读取

### 7) 分页区域

- 典型特征：`ant-pagination`、当前页、高亮页码、下一页按钮
- 定位顺序：目标表附近分页器 -> 下一页 ref
- 执行动作：翻页 -> 等待 -> 重读
- 后置校验：页码变化且首行变化（或总行累计变化）

### 8) 下载/导出

- 典型特征：下载/导出按钮或菜单项
- 定位顺序：目标区块内下载入口 ref -> 下载确认控件 ref
- 执行动作：优先提取 URL 后 `browser_navigate`；无法提取时仅 1 次点击探测
- 后置校验：本地文件落盘（文件名关键字 + 修改时间 + 大小 > 0）

## 统一失败信号

- `ambiguous text match`
- `input not found` / `element not found`
- 动作返回成功但关键状态未变化
- 连续两次使用同策略仍失败

遇到失败时，回到 `error-recovery.md` 执行分流恢复。
