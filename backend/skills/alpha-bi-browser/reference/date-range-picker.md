# 日期范围选择器（Date Range Picker）

## 适用范围

- 过滤区存在“当期”“对比期”等标签
- 输入框常见文案为“开始日期”“结束日期”
- 输入框通常为只读，需要通过面板点击日期单元格
- 双面板日历（左月/右月）与截图一致

## 组件行为模型（关键）

该类 RangePicker 的正确交互是：  
**打开一次面板 -> 选开始日 -> 不关闭面板 -> 选结束日 -> 自动形成区间**。

如果“选了开始日后关闭面板，再重新打开选结束日”，组件通常会把第二次点击当作新的开始日，最终只剩单日。

## 强制规则

1. 单个日期范围必须在同一次面板会话中完成。
2. 选完开始日后，禁止再次点击输入框打开/关闭面板。
3. 结束日通过日历单元格直接点击，不走输入框。
4. 选完结束日后再做一次 snapshot 校验显示为 `start ~ end`。

## 标准操作流程（同月）

1. `browser_snapshot` 定位目标区块（当期/对比期）内的“开始日期”输入框。
2. 点击“开始日期”输入框，确认面板已打开。
3. 在当前面板点击开始日（例如 1 号）。
4. **不要关闭面板**，继续在同一面板点击结束日（例如 31 号）。
5. `browser_wait` 0.3~0.8 秒后 snapshot，校验输入区显示区间。

## 标准操作流程（跨月）

1. 打开面板后先选开始日（左面板目标月）。
2. 在面板内使用月切换按钮，使右面板出现结束月。
3. 在右面板点击结束日。
4. 等待并校验显示为跨月区间。

## Browser MCP 操作序列（伪代码）

```text
1) browser_snapshot() -> 找到 "当期" 区块 + 开始日期 input ref
2) browser_click(ref=start_input_ref) -> 打开面板
3) browser_snapshot() -> 找到开始日 cell ref
4) browser_click(ref=start_day_ref) -> 仅设置起点
5) browser_snapshot() -> 找到结束日 cell ref (面板保持打开)
6) browser_click(ref=end_day_ref) -> 完成区间
7) browser_wait(seconds=0.5)
8) browser_snapshot() -> 校验 "YYYY-MM-DD ~ YYYY-MM-DD"
```

## 定位优先级

1. 标签文本锚定（当期/对比期）+ 就近输入框
2. `browser_snapshot` 返回的 ref
3. 日历面板中的日期单元格文本

## 组件元素特征（可固定）

以下特征可用于识别日期范围组件并加速定位：

- 日期输入区域常见 `ant-calendar-picker` / range 输入结构
- 面板层常见 `ant-calendar-range` 与左右双面板布局
- 月切换按钮与日期单元格（`td`/可点击日期文本）的组合结构

注意：固定到“组件模式”即可，不要绑定具体报表页的绝对 XPath 或单次快照 ref。

## 反模式（禁止）

- 选了开始日后关闭面板，再重新打开选结束日。
- 对只读输入框执行 `browser_type`。
- 在没有 snapshot 刷新的情况下复用旧 ref 连续点击。

## 失败信号与恢复

- 失败信号：只显示一个日期、日期被覆盖、区间未形成。
- 恢复步骤：
  1. 清空当前值（按页面支持方式：重置或重新选区间）。
  2. 重新打开面板后一次完成“开始+结束”。
  3. 每次点击后 snapshot，确保使用最新 ref。
