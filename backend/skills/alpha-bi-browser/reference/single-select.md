# 单选下拉组件（Single Select）

## 适用范围

- 常见于“聚合维度（指标卡）”“品类组（指标卡）”“采一/采二/采三”
- 展开后只能选择一个值

## 标准操作流程

1. 先锚定目标区块（示例：`<目标章节标题>` + `<目标表/模块标题>`）。
2. `browser_snapshot` 获取该区块内目标字段（示例：`<目标字段>`）下拉 ref。
3. 点击该下拉展开选项列表。
4. 立即 `browser_snapshot`，只使用“当前已展开列表”的 option ref。
5. 点击目标选项（示例：`<目标选项>`）。
6. `browser_wait` 0.2~0.5 秒。
7. 强校验：字段展示值必须等于目标值；否则视为失败并进入恢复流程。

## 单选字段示例模板（强约束）

当任务要求“将 `<目标字段>` 设为 `<目标选项>`”时，按以下顺序执行：

1. 锚定 `<目标表/模块标题>` 区块。
2. 点击该区块的 `<目标字段>` 下拉。
3. 在当前展开列表中点击 `<目标选项>`。
4. 校验下拉展示值等于 `<目标选项>`。
5. 校验通过后才允许进入下一步（如勾选维度、点击查询）。

## 定位优先级

1. 区块锚定（标题/表名）+ 字段文本
2. 下拉框当前展示文本
3. 展开后选项的 ref + 文本

## 组件元素特征（可固定）

以下特征可作为“识别单选组件”的稳定信号，用于提升定位速度与准确率：

- `ant-select` / `ant-select-selection` 样式特征
- 字段标签文本与下拉框相邻容器关系（同一筛选行/卡片）
- 展开后选项容器的 `ant-select-dropdown` 结构

注意：可固定“组件特征”，不要写死某一页的深层路径、临时 ref 或绝对层级。

## 备用策略

- 先点击标签文本区域激活组件，再 snapshot 重取 ref。
- 若选项列表滚动，先滚动到目标项可见再点击。
- 若点击目标后值不匹配，关闭下拉重开并重取 option ref。
- 必要时改用键盘选择（方向键 + Enter）并再次校验。

## 键盘兜底模板（固定序列）

适用场景：

- 鼠标点击 option 后经常选到相邻项
- 虚拟列表导致 option ref 不稳定

执行模板（在已展开下拉前提下）：

1. 记录当前高亮/选中项文本。
2. 根据目标项相对位置发送 `ArrowDown` / `ArrowUp`（逐步移动）。
3. 每移动 1~2 次可做一次轻量校验（避免越位）。
4. 到达目标项后发送 `Enter` 确认。
5. 校验字段展示值必须等于 `<目标选项>`。

## 反模式（禁止）

- 未锁定区块就直接点击“品类组”。
- 复用展开前的 option ref 去点击展开后的选项。
- 点击目标项后不做值校验直接进入下一步。
- 连续多次盲点同一选项。

## 失败信号与恢复

- 失败信号：
  - 下拉已展开但无法选中
  - 点击目标项后展示成其他值（示例：点了 A，展示成 B）
  - 选中后立即恢复旧值
- 恢复步骤：
  - 关闭下拉并重新展开
  - 重新 snapshot 后使用“当前展开列表”的最新 ref
  - 每次点击后执行展示值校验
  - 两次失败后切换键盘选择策略或上报异常
